# 优化后的八个独立因子

独立入口：`factor.optimized.get_optimized_factor_definition(name)`；可把返回的定义传给 `factor.precompute_factors(..., definitions=(definition,))`。这是因子目录，不是权重、N/M/p 或策略组合预设；生产 registry、默认配置与实盘账户不变。

| 名称 | 固定计算与参数 | 全周期20日 Rank IC |
|---|---|---:|
| TrueMarketCap | 负的当日开盘价×前一日股本，小市值优先；沿用历史分数缩放 | 0.057016 |
| VolumeCV | 前20个完成日成交量标准差/均值的负值 | 0.045777 |
| AmountBasedSmallCap5 | 前5个完成日有效成交额均值A，100×exp(−A/5亿元) | 0.119228 |
| BiliAdjustedIssueDiscount | IPO锚定、逐日因果复权价格相对发行价折价，复用原实现 | 0.036611 |
| PB3ROE5Signal | PB<3且ROE>5%，满足为1、不满足为0；无有效财务/股本为NaN | 0.032527 |
| ProfitGrowthOriginalAvailability | 利润同比增长，惩罚系数λ=0；仍要求原利润与现金流出增长两字段都有效 | 0.029689 |
| BiliLowReturnAttention10 | 前10个完成日相对PIT等权市场收益偏差绝对值的最大值取负 | 0.101785 |
| LowResidualVol20 | 前20个完成日个股收益减PIT等权市场收益的总体标准差取负；不是回归残差 | 0.111072 |

PB单位：total_share为万股，先乘10000换成股；权益与利润均为元。股本由FactorMetadata声明滞后一日，避免调用端漏lag或重复lag。连续小市值分数保留旧缩放，排序不受统一正比例缩放影响；不能把该分数直接解释为准确亿元市值。

前三项保留当前开盘价≥2元、非ST有效性门。VolumeCV需20日warmup，沿用累计核对缺失成交量的有效观测计算；Amount5同样沿用原累计核的有效观测与warmup规则。注意力及残差波动必须窗口内每一天有效，初始与窗口缺失保持NaN，真实数值0保持有效。因子层不替调用方填值；如后续组合启用ffill，必须仅用过去观测，未曾有效的初始缺失保持无效，不能用0参与排名。

这些参数来自已观察2005—2025全周期IC筛选，IC不是净收益或新盲测结果。正式组合、权重、仓位和交易参数留待单独决定。未引入新的训练或账户回放。

来源：封存研究ga8_optimized_buffer_3seed_20261104/source。移植只把三个已存在的因子加上研究时相同的有效性门，并将缺失的窗口辅助函数纳入模块，避免依赖未提交研究文件；五个优化信号数学定义保持一致。

## 验证

4项单元测试覆盖PB单位和严格阈值、股本滞后、原始有效性、已完成窗口、初始缺失和未来扰动。基于提交前HEAD与仅本次4文件构造的干净副本同样通过；该副本重算2005—2025全部8个原始因子矩阵，与已审IC原数组逐元素精确一致（含NaN），耗时24.48秒，新增账户回放0。实物证据保存在本地artifacts/research/optimized_factor_git_20261105/raw_parity_result.json；无需研究大数据才能运行因子模块及单元测试。
