## 策略与迁移是否等价

52 天具备旧计划、前日持仓和现金，可用当前策略逐日 seed 重算。其中 27 天买卖净股数完全一致，25 天不一致；9月起为 35 天中 27 天一致。11/2 和 11/3 均完全一致。

同一日计划转为绝对目标再计算净股数，52/52 天保持一致。这只证明 JSON 转换没有改变计划股数，不等于 52 天都实际成交，也不是完整 publisher 启动路径验收。

相对最后一次 Git 提交（2026-07-06），存在实质变化：

- 四因子权重保持 Amihud 0.4、TrueMarketCap 0.9、VolumeCV 0.1、AmountBasedSmallCap 0.6。
- buy_n 仍为20，sell_m 从20变25，且核心实现新增真正保留 Top25 中已有持仓的语义。
- prefilter_n 从1200变300，新增当日候选池内因子重排名。
- 执行由旧版持久挂单行为增加开盘限价超时撤单、对手价重报。

因此 Git 旧版本与当前不是只替换 Python 运行环境。Git HEAD 也不能冒称11月2日部署版本：缺少历史逐日源码/配置身份，无法精确给所有差异划分发生时间。

当前 seed 重算使用现有历史日线，不是当时原始盘前报价；以 T-1 现金持仓作为盘前起点，并假设隔日可卖。它适合定位差异，不足以把全部差异判为迁移缺陷。例：10/30 原计划买688671.SH 2090股，当前重算0股；原卖688701.SH 234股，重算245股。原 plan 与 execution pending 相同，两股原计划开盘价也与当前历史价相同，但缺更详细排名/目标金额证据，仍未完全归因。
